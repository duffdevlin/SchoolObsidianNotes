# Courses by Content
Here you will find courses separated into groups based on the culminated learning objectives of the courses within. Each section contains courses ordered in a way that established base concepts before expanding on them in courses further down the list. While courses were ordered for the most linear learning possible, some courses were meant to be taken simultaneously, and these courses will reference the linked neighbouring course as the information becomes relevant. Some unlisted courses may still contain required content for complete understanding, but these too will be referenced as required. The intended experience if using this as a learning tool is to begin at the top of these lists and work your way down as you learn the previous course's material.
